Sobre o projeto

O OSDR (Open Science Data Repository) é o repositório aberto da NASA com dados de experimentos de biologia espacial: estudos sobre como plantas, animais, microrganismos e células reagem a voos espaciais e à microgravidade. Cada estudo recebe um código de identificação (accession) e pode ser consultado por uma API pública.

Este projeto, do Grupo 10, monta um pipeline de dados automatizado: coleta os estudos pela API do OSDR, guarda tudo em um banco de dados e exibe os resultados neste painel, que você pode explorar com a busca e os filtros abaixo.
